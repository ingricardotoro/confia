### Reglas comunes a todas las tareas

- **Regla de las 800 líneas: se detiene antes de comprometer.** Antes del primer commit de cada PR, y otra vez antes de cada commit siguiente, se mide:

':(exclude)openspec' ':(exclude)pnpm-lock.yaml' ':(exclude)packages/contracts/src/generated'`, sumando adiciones y eliminaciones. **Si supera 800, el PR no se compromete.** El ejecutor se detiene y registra la medida en `apply-progress.md`. Entonces:
  - si supera 800 **solo por poco**, no corta: pide al propietario una excepción explícita (hasta 880 líneas efectivas, por decisión del propietario del 2026-11-07; por encima de 880 se aplica el corte);
  - si la supera **claramente**, aplica el corte predefinido de su tarea, por archivos completos y con las pruebas junto a su código, y vuelve a medir cada parte antes de comprometerla;
  - si la tarea no tiene corte, o una parte sigue sobre 800, **no compromete y consulta**.

  Nunca se quitan pruebas, se minifica ni se borran comentarios o líneas en blanco para caber.
- **Suite completa de cada superficie tocada.** Las órdenes focalizadas son solo para iterar; ninguna tarea se cierra con ellas. Cada tarea cierra con la suite de cada ruta que tocó y además con la prueba de PR completo.
